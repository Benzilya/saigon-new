# Saigon VN — new website

Новый коммерческий сайт ресторана Saigon VN в Королёве.

## Концепция

Тёмная версия выбранного пользователем второго дизайн-направления: чистая структура, тёплые оттенки дерева и света, золотые/красные акценты и быстрый доступ к главным действиям — меню, звонок и маршрут.

## Технологии

- semantic HTML5
- responsive CSS без UI-фреймворков
- минимальный vanilla JavaScript только для мобильной навигации
- Restaurant schema.org markup
- mobile sticky action bar
- responsive breakpoints для 375 / 430 / 768 / 1024 / 1440 px

Никакой сборки не требуется: `index.html` можно открывать напрямую или публиковать через GitHub Pages / любой статический хостинг.

## Источники фактических данных

Контакты, адрес, рейтинг и отзывы взяты с текущего сайта Saigon VN / карточки Яндекс. Неизвестные часы работы и цены намеренно не выдуманы. Кнопка «Меню и цены» ведёт в текущий каталог ресторана, пока структурированное меню не будет перенесено в репозиторий.

Фото блюд и интерьерный референс в текущей версии — свободные фотографии Unsplash. Кнопка «Посмотреть реальные фото» ведёт в официальную галерею Saigon VN на Яндекс Картах. При получении оригинальных фотографий их можно заменить без изменения структуры страницы.

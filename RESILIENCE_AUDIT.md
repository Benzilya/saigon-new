# SAIGON VN — resilience audit

Проверка выполнена для четырёх групп внешних зависимостей: изображения, шрифты, Яндекс Карты и внешние ссылки.

## 1. Изображения

Видимые изображения сайта должны иметь локальный источник в репозитории. Слой `local-assets.css` принудительно использует локальные файлы для hero и legacy-карточек, а `theme.css` уже использует локальные версии интерьера для светлой и тёмной темы. Фотографии меню, которые выводятся через `menu.js`, также берутся из `assets/menu/`.

Ключевые локальные ресурсы:

- `assets/hero/pho-bo-hero.jpg`
- `assets/interior/interior-dark.webp`
- `assets/interior/interior-light.webp`
- `assets/menu/*.webp`
- `assets/branding/*`

Ссылки на Unsplash, оставшиеся в базовом CSS как исторические значения, перекрываются последним подключённым `local-assets.css` и не являются источником отображаемых изображений.

## 2. Google Fonts

Google Fonts остаётся визуальным улучшением, но не является обязательной зависимостью для работы сайта. В `local-assets.css` задан расширенный fallback:

- sans-serif: `Manrope → Segoe UI → Roboto → Helvetica → Arial → sans-serif`
- serif: `Prata → Georgia → Times New Roman → serif`

Если Google Fonts заблокирован VPN, DNS-фильтром, расширением или сетью, текст остаётся читаемым и интерфейс не теряет функциональность.

## 3. Яндекс Карта

Iframe Яндекс Карт считается дополнительным интерактивным элементом, а не единственным источником контактной информации. Вне iframe на странице постоянно доступны:

- полный адрес ресторана;
- номер телефона;
- кнопка звонка;
- кнопка построения маршрута.

Поэтому при блокировке или ошибке iframe пользователь всё равно получает критически важные контактные данные и может связаться с рестораном.

## 4. Внешние ссылки

Основное меню, цены, выдержки из отзывов, адрес и телефон отображаются непосредственно на сайте. Ссылки на Яндекс Карты и `saigonvn.clients.site` используются как дополнительные переходы для сверки меню, просмотра реальных фотографий, отзывов и маршрута; они не нужны для рендера основного контента.

Внешние переходы открываются отдельно с `rel="noopener"` там, где используется `target="_blank"`.

## Дополнительная QA-защита

В мобильном режиме уменьшены размеры текста блока рейтинга и карточек отзывов, чтобы избежать визуально чрезмерной типографики на небольших экранах.
